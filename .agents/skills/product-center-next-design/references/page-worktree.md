# 商品中心 Next 全量页面优化工作树

本工作树是 UI 与交互优化的范围基线。不得用“商品资料”“渠道经营”等模块名称代替其内部页面，也不得因某个能力采用页内 Tab、抽屉或向导而从计划中省略。

## 完成口径

每个设计单元都必须交付：页面契约、字段、按钮、弹窗/抽屉、状态、权限、主流程、异常恢复和高保真原型。只有覆盖矩阵完成并经用户确认，才标记为完成。

## 06 横向公共能力

这些能力不一定拥有独立菜单，但每个相关页面必须复用一致交互：

- 商品、分类、渠道、组织、区域、门店和人员选择器。
- 导入五段式流程：模板、上传、校验、预览、执行/结果。
- 导出范围与脱敏确认。
- 异步任务、进度、部分成功、失败明细、重试和结果导出。
- 对象详情、字段前后值、操作人、时间和来源任务审计。
- 权限不足、部分权限、范围越权、授权失效和敏感字段脱敏。
- 并发冲突、幂等、防重复提交、未保存离开和恢复草稿。
