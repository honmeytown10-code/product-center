# 03. 渠道经营

## 1. 页面范围

渠道经营包含：渠道商品（仅分渠道协作显示，页内含商品、渠道分类、渠道属性）、商品模板、销售规则、商品推荐。这里回答“商品准备怎么卖”和“区域/门店存在什么经营差异”，不承担门店即时库存，也不直接维护平台真实商品。

---

# 2. 渠道商品

## 2.1 页面契约

| 项目 | 规格 |
| --- | --- |
| 建议路由 | `/goodsCenter/channel-products` |
| 显示条件 | 品牌为分渠道协作，且账号至少有一个渠道商品库权限 |
| 主要角色 | 渠道负责人、统一商品运营、实施 |
| 主任务 | 从主档加入商品并维护当前商品库的销售资料与平台扩展 |
| 主骨架 | 商品库上下文 + 状态 Tab + 筛选 + 高密度表格 |

## 2.2 范围上下文条

字段：当前商品库、商品库 ID、包含渠道、企迈管理/平台维护标记、账号可管理渠道、门店范围、负责人、最近发布、待办数量。

按钮：切换商品库、查看渠道范围、查看权限、进入全渠道配置（管理员）、刷新平台规则。

切换商品库保留通用筛选，清理渠道专属筛选并回到第一页；有选中项或未保存列编辑时先确认。

## 2.3 状态 Tab

| Tab | 定义 |
| --- | --- |
| 全部 | 当前商品库全部非归档渠道商品 |
| 待完善 | 公共或平台必填资料缺失 |
| 待确认 | 主档新增规格、做法、加料尚未确认是否启用 |
| 可发布 | 当前选择渠道满足发布前置条件 |
| 发布中 | 存在执行中的发布任务 |
| 发布失败 | 最近有效批次存在失败范围 |
| 已发布 | 至少一个门店/渠道完成发布 |
| 已归档 | 已移出所有适用渠道但保留历史 |

## 2.4 筛选字段

| 字段 | 控件 | 规则 |
| --- | --- | --- |
| 商品名称/ID/SKUID/编码 | 关键词 | 回车查询 |
| 主档分类 | 树选择 | 只读主档分类路径 |
| 前台分类 | 树选择 | 默认取商品主档值，可筛选并覆盖当前商品库归属；不在此新增或修改分类定义 |
| 商品类型 | 多选 | 标准、套餐等 |
| 适用渠道 | 多选 | 仅当前商品库包含渠道；按自营/三方分组 |
| 资料状态 | 多选 | 缺图、缺分类、缺价格、缺平台字段、规则已变化 |
| 结构确认 | 多选 | 无变更、待确认 SKU、待确认做法、待确认加料 |
| 发布状态 | 多选 | 未发布、发布中、部分成功、失败、已发布 |
| 映射状态 | 多选 | 仅三方渠道相关摘要 |
| 数据来源 | 多选 | 主档加入、导入、迁移、API |
| 更新时间/更新人 | 日期/人员 | 展开筛选 |

## 2.5 操作栏

| 按钮 | 级别 | 行为 |
| --- | --- | --- |
| 从主档加入 | 主按钮 | 打开商品选择弹窗；自动排除已存在商品 |
| 创建发布 | 次按钮 | 选中商品时带入；未选中时进入发布中心再选 |
| 批量修改 | 次按钮 | 选择字段、目标商品和覆盖方式 |
| 导入 | 次/更多 | 按当前商品库与渠道能力动态生成模板 |
| 导出 | 更多 | 导出当前快照和可维护字段 |
| 列设置 | 图标 | 渠道专属字段可按渠道分组 |
| 查看任务 | 更多 | 导入、批量修改和发布任务 |

## 2.6 表格字段

| 列 | 显示规则 |
| --- | --- |
| 选择 | 支持本页/筛选结果全选 |
| 商品 | 渠道图片、渠道名称；下方显示主档名称、商品 ID、SKUID |
| 商品类型/规格 | 类型、SKU 数、启用 SKU/总 SKU |
| 主档分类 | 只读，完整路径 |
| 前台分类 | 当前商品库最终有效值，多项 +N；可查看来源为主档默认或当前商品库覆盖 |
| 价格 | 起售价/价格区间；成本价按权限 |
| 覆盖渠道 | 图标 + 名称；平台维护渠道不会进入此列 |
| 资料状态 | 完整/缺失项数量/平台规则变化 |
| 结构确认 | 待确认 SKU、做法、加料数量 |
| 发布状态 | 按渠道显示摘要，点击看门店范围 |
| 映射状态 | 三方企迈管理渠道显示异常数 |
| 最近发布 | 批次编号、时间、结果 |
| 更新时间 | 时间 + 更新人 |
| 操作 | 编辑、发布、更多 |

## 2.7 行内与批量按钮

行内：编辑、发布、查看详情；更多包含查看主档、查看发布记录、复制渠道资料、移出商品库、归档、日志。

批量：修改前台分类归属、图片/描述、改价、启停 SKU/做法/加料、确认主档变更、创建发布、移出商品库、导出已选。批量修改前台分类仅写入当前商品库覆盖值；分类定义需回商品主档处理。

批量修改必须先选字段，再选择“统一设置一个值”或“通过文件逐项修改”。不同渠道规则冲突时按商品/渠道列出阻止项。

## 2.8 渠道分类与渠道属性视图

渠道商品页使用稳定页内视图“商品 / 渠道分类 / 渠道属性”。三者共享当前商品库、包含渠道、权限范围和发布状态，不新增左侧菜单，也不能把后两者省略为编辑页中的几个字段。

### 渠道分类

布局：左侧渠道售卖分类树，右侧分类信息、关联商品和平台类目映射。支持按当前商品库公共分类查看，也支持切换具体平台检查映射结果。

字段：分类名称/ID、上级分类、图片、排序、状态、适用渠道、平台类目映射、关联商品数、待发布差异、更新时间/更新人。

按钮：新建子分类、编辑、移动、调整排序、关联商品、映射平台类目、启停、删除、创建发布、查看日志。删除前检查子分类、商品引用和有效发布快照。

弹窗/抽屉：分类编辑弹窗、移动分类弹窗、商品关联大弹窗、平台类目映射抽屉、启停/删除影响确认、批量排序未保存提示。

### 渠道属性

布局：顶部“公共属性 / 平台扩展属性”视图，左侧属性或平台分组，右侧属性列表与值映射。

字段：属性名称/ID、属性类型、可选值、适用类目、适用商品数、适用渠道/平台、平台字段映射、动态必填、规则版本、校验状态、更新时间/更新人。

按钮：新建公共属性、编辑、管理属性值、关联分类/商品、同步平台规则、配置值映射、启停、删除、重新校验、查看影响。

弹窗/抽屉：属性编辑弹窗、属性值管理抽屉、分类/商品选择器、平台字段和值映射大弹窗、规则变化影响抽屉、启停/删除确认。

平台规则同步后保留旧值，标记新增必填、类型变化、值失效和待重新校验；不得静默覆盖用户已维护的渠道资料。

## 2.9 渠道商品编辑页面

```text
范围上下文条
主档身份摘要（只读）
左侧锚点：销售资料 / 可售结构 / 展示资料 / 渠道属性 / 发布状态
中间表单
右侧：继承与覆盖摘要、当前渠道预览（按需）
底部：取消 / 保存 / 保存并发布
```

### 主档身份摘要（只读）

商品名称、商品 ID、SPU/SKU、商品类型、规格结构、做法全集、加料全集、后台分类、主档状态、最近结构变化。按钮：“查看主档”。

### 销售资料字段

| 字段 | 继承/覆盖规则 |
| --- | --- |
| 渠道商品名称 | 默认继承主档/品牌公共值；可覆盖 |
| 商品别名 | 可覆盖 |
| 前台分类 | 默认从商品主档继承；可作为筛选和发布资料，并可覆盖当前商品库归属；不允许在渠道页修改分类定义 |
| 渠道售价/市场价 | SKU 级维护；不展示主档参考价，支持批量填充 |
| 库存管理 | SKU 级维护渠道库存策略及配置值；门店实时库存仍在门店商品处理 |
| 包装费 | SKU 级维护到店外带/外卖配送包装费和包装标识，按渠道能力出现 |
| 售卖时段 | 商品库公共值；平台限制动态校验 |
| 起购/限购 | 渠道值不得违反平台上限 |
| 会员/折扣 | 仅支持渠道显示 |
| 税率/开票 | 按渠道和业务配置 |
| 售卖状态初始值 | 只决定首次发布，不直接修改门店即时状态 |

### 可售结构

规格/SKU、做法、加料均来自主档只读结构。规格按“规格值”控制可售子集，禁用一个规格值会使全部包含该值的 SKU 不可售；SKU 表不再提供独立启停开关，避免绕过规格值规则。做法、加料仍按候选项控制启用范围，所有结构均不可新增、删除、改名或换组。

页面默认直接展示 SKU 销售配置，不常驻展开规格值区。SKU 表标题右侧展示“已禁用 N 个规格值”和“配置规格值”按钮；弹窗字段包括规格值、关联 SKU 数、渠道可售开关、主档状态和待确认状态，取消不保存、保存配置后回写表单。SKU 销售配置字段：规格组合、渠道销售价、市场价、商品标识、商品规格码、商品编码、条码、库存管理、包装费/包装标识、最终可售结果。其中四类识别字段只读，SKU ID不在日常列表展示。

主档新对象默认禁用并标记“待确认”；确认弹窗说明启用后会进入哪些渠道、模板和下一次发布。

### 展示资料

主图、列表简述、描述标签、点单标签、角标、视频、详情描述。每项显示继承来源、覆盖状态、恢复继承。素材字段使用统一素材库。

### 渠道属性

按覆盖渠道分组。公共字段只显示一次；平台类目、平台图片、审核资料、配送包装等专属字段动态来自平台能力矩阵。

每个字段展示：字段名称、来源平台、是否必填、格式/长度、当前规则版本、校验状态。平台规则变化时旧值保留但标记待重新校验。

## 2.10 弹窗/抽屉

| 名称 | 字段/内容 | 按钮 |
| --- | --- | --- |
| 从主档加入商品 | 搜索、分类、商品类型、未加入原因、已选区 | 取消、加入 N 个商品 |
| 加入结果 | 新增、已存在、无权限、失败及原因 | 查看失败、继续维护 |
| 批量修改 | 字段、目标范围、值、覆盖继承、预检摘要 | 预览影响、创建任务 |
| 主档变更确认 | 新增/停用对象、下游影响、逐项启用选择 | 稍后处理、确认更新 |
| 复制渠道资料 | 来源商品库、目标商品库、字段范围、冲突处理 | 校验、创建复制任务 |
| 移出商品库 | 商品/SKU 数、覆盖渠道、模板/发布引用、归档结果 | 返回、确认移出 |
| 资料缺失抽屉 | 按公共/平台分组的缺失字段、定位入口 | 去完善 |
| 发布摘要抽屉 | 渠道、门店、批次、成功/失败、映射 | 查看批次 |

# 3. 商品模板

## 3.1 页面契约

| 项目 | 规格 |
| --- | --- |
| 建议路由 | `/goodsCenter/templates` |
| 主任务 | 管理同一商品来源下的商品集合、区域/门店和经营差异 |
| 主要角色 | 总部、渠道、区域运营 |
| 强约束 | 先选渠道，系统自动判定唯一来源；用户不能手工选来源 |

## 3.2 列表

### Tab/筛选

Tab：全部、启用、停用、待完善、发布失败。  
筛选：模板名称/ID、适用渠道、商品来源摘要、区域/门店、状态、发布状态、更新人、更新时间。

### 表格字段

模板名称/ID、描述、适用渠道、自动判定来源、商品数/SKU 数、适用门店数、经营覆盖项、状态、最近发布、更新时间、操作。

### 按钮

页面：新建模板、导入模板商品、导出、列设置。  
行内：管理商品、编辑、发布；更多：复制模板、适用门店、停用/启用、删除、日志。

## 3.3 创建/编辑步骤

```text
1 基础信息与渠道
2 自动判定来源
3 添加商品
4 配置经营差异
5 适用门店
6 校验与保存/发布
```

### 步骤 1：基础信息与渠道

字段：模板名称（必填）、描述、启用状态、适用渠道（必填）、业务标签、负责人。

渠道选择只显示当前账号有权限且可作为模板目标的渠道；来源不兼容渠道在选择首个渠道后禁用并解释原因。

### 步骤 2：来源摘要（只读）

字段：来源类型、来源对象名称/ID、判定依据（协作方式、渠道策略、商品库分组）、适用渠道、规则版本。

来源冲突时阻止下一步，展示冲突渠道和拆分建议。按钮：“调整渠道”“复制为两个模板”。

### 步骤 3：添加商品

表格：商品、SKUID、类型、分类、资料状态、可用 SKU、渠道适配、已选。  
筛选：名称/ID、分类、类型、资料状态。  
按钮：添加商品、移除、全选筛选结果、导入商品 ID、查看不可选原因。

### 步骤 4：经营差异

按能力显示可覆盖字段：前台分类归属、价格、售卖时段、SKU 启用、做法/加料启用、展示资料、必选/互斥规则、推荐等。每项默认“继承来源”，开启覆盖后显示具体控件；前台分类只能选择主档已定义且启用的分类。

字段必须展示继承值、覆盖值、差异商品数和恢复继承。

### 步骤 5：适用门店

组织/区域/门店选择器；字段：适用范围类型、区域、门店、排除门店、预计门店数、授权完整数、冲突模板数。

### 步骤 6：校验

校验来源唯一、资料完整、门店权限、授权、平台必填、多模板冲突。结果按错误/警告展示，错误阻止保存，警告需确认。

## 3.4 底部按钮

上一步、保存草稿、下一步；末步显示“仅保存模板”“保存并创建发布”。编辑时另有“放弃修改”。

## 3.5 弹窗

- 渠道选择弹窗：按来源兼容性禁用选项。
- 来源冲突弹窗：冲突渠道、对应来源、拆分动作。
- 商品选择大弹窗：双列表、筛选和不可选原因。
- 门店选择大弹窗：组织树、门店表格、已选区。
- 多模板冲突弹窗：门店、渠道、SKU、动作、冲突模板；支持移除或复制拆分。
- 删除模板弹窗：最近发布、门店覆盖、历史保留说明。
- 复制模板弹窗：新名称、渠道、门店、复制字段范围；复制后重新判源。

# 4. 销售规则

## 4.1 页面结构

建议路由 `/goodsCenter/sales-rules`，页内左侧视图或顶部二级 Tab：价格策略、售卖范围、属性互斥、必选商品。

各类规则共用字段：规则名称/ID、规则摘要、适用渠道、适用门店、优先级、启用状态、有效期、冲突状态、更新时间、操作。

## 4.2 价格策略

### 列表筛选/字段

筛选：策略 ID、名称、机构/门店、渠道、启用状态、生效日期、冲突状态。  
字段：名称/ID、状态、渠道、售卖类型、日期/周期/时段、适用门店、商品数、冲突、更新时间、操作。

按钮：新增价格策略、查看策略说明、价格管理、适用门店、编辑、复制、启停、删除、日志。

### 策略基础字段

策略名称（必填）、描述、启用状态、优先级、生效日期、星期、时段、时区、渠道、售卖类型、区域/门店、排除门店。

### 商品价格矩阵

字段：商品、SKU、当前来源价、策略价、差额、差异百分比、最低/最高限制、校验状态。按钮：添加商品、批量填价、按金额/比例调价、导入、导出、恢复来源价。

提交前校验同门店、渠道、时间、SKU 的策略冲突。价格 `0` 合法时必须明确显示，空值为 `--`。

## 4.3 售卖范围

### 列表字段

规则名称、商品/分类范围、适用渠道、区域/门店、有效期、优先级、启用状态、覆盖商品数、更新时间、操作。

### 编辑字段

规则名称、对象类型（商品/分类/标签）、对象选择、渠道、区域/门店、排除门店、售卖开始/结束日期、星期/时段、售卖/停售动作、优先级、状态、备注。

## 4.4 属性互斥

# 5. 商品推荐

## 5.1 页面契约

| 项目 | 规格 |
| --- | --- |
| 建议路由 | `/goodsCenter/recommendations` |
| 主任务 | 配置在特定商品、分类、渠道和门店范围内展示哪些推荐商品 |
| 主骨架 | 规则列表 + 独立创建编辑页面 |

## 5.2 列表

Tab：全部、启用、停用、未生效、冲突。  
筛选：规则名称/ID、触发对象、推荐对象、渠道、机构门店、状态、有效期。  
字段：规则名称、触发对象、推荐商品数、推荐方式、渠道、门店、优先级、有效期、状态、更新时间、操作。

按钮：新建推荐、排序管理、导入、编辑、预览、复制、启停、删除、日志。

## 5.3 编辑字段

| 分组 | 字段 |
| --- | --- |
| 基础 | 规则名称、描述、启用状态、优先级 |
| 触发 | 触发类型（商品详情/分类/购物车等）、触发商品/分类、触发条件 |
| 推荐内容 | 推荐商品/SKU、排序、固定/智能顺序、售罄处理、最大展示数 |
| 范围 | 渠道、区域/门店、排除门店 |
| 时间 | 开始/结束日期、星期、时段、时区 |
| 展示 | 标题、样式类型（由前台能力提供）、曝光频控 |

推荐商品选择器显示当前渠道是否可售、库存/上下架摘要和不可选原因，避免选择无法展示的商品。

## 5.4 按钮与弹窗

- 编辑页按钮：取消、保存草稿、保存并启用、预览效果。
- 推荐商品选择大弹窗：渠道可售筛选、已选区、拖拽排序。
- 冲突弹窗：同触发对象、渠道、门店和时间的规则，显示优先级结果。
- 前台预览抽屉：选择渠道和典型终端，仅作为结构预览，不伪造真实前台样式。
- 启停/删除确认：影响范围、生效时间、历史数据保留。

## 5.5 状态与异常

覆盖：触发对象已停用、推荐商品全部不可售、部分门店无商品、渠道不支持推荐样式、规则时间冲突、无门店权限、发布未完成导致暂不可见。
