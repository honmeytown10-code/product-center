# 商品中心 PC 后台全页面覆盖清单

更新时间：2026-08-01。此清单是后续继续实现、评审和回归的唯一覆盖索引；“完成”指本工作树已完成可操作原型与 UI/交互收口，不代表外部平台 API 已上线。

## 1. 全局约束

- 页面主任务是数据管理时，不显示大面积标题、说明文案或策略介绍卡；首屏优先给状态、筛选、快捷导航、表格和主操作。
- 商品工作台允许保留紧凑标题；详情抽屉固定覆盖主页面，禁止挤压列表。
- 页面和侧栏隐藏可见滚动条但保留滚动；表头、操作列、批量坞和弹窗底栏按场景固定。
- 商品仍只有标准商品、套餐商品两种；两者各自类目和字段沿用原系统。
- 统一维护模式显示“商品管理”，同时提供前后台分类筛选；分渠道协作显示“商品主档 + 渠道商品”，主档用后台分类、渠道商品用前台分类。
- 分渠道协作显示“渠道分类与属性”；“门店与平台绑定”和独立“全渠道配置”不属于侧栏菜单。
- 主操作有结果；危险操作有影响范围与确认；未接入能力明确禁用并显示原因。

## 2. 页面与交互覆盖

| 菜单/稳定子页 | 已完成范围 | 策略联动 | 生产接入边界 |
| --- | --- | --- | --- |
| 商品工作台 | 任务分组、筛选、批量指派/忽略/处理、可收起批量坞、覆盖式详情抽屉、范围切换、加载/空/错误/无权态 | 按当前协作方式显示职责事实；任务不写死为可配置流程 | 负责人解析、SLA、升级与提醒规则待业务和接口确认 |
| 商品管理/商品主档 | 状态、原筛选字段、前后台分类快捷导航、表格、排序、导入导出、批量启停、回收站反馈、详情与编辑 | 统一模式前后台分类均可切换；分渠道主档只用后台分类 | 服务端分页、权限和批量部分失败待接口 |
| 标准商品创建/编辑 | 原字段、原类目、规格/做法/加料选择、校验、保存、后续任务入口 | 统一模式保存统一资料；分渠道模式只保存主档资料 | 素材、部分属性库新增和异步任务详情待接入 |

| 分类与属性 | 后台/前台分类、规格、做法、加料、关联/解除商品、列设置边界、删除/引用确认 | 统一模式提供前后台分类；分渠道主档职责只维护后台定义 | 部分属性库的生产权限与接口待接入 |
| 配方与营养 | 配方列表/详情、组合维度、配料库、加料分组、营养值、门店策略、导入导出与危险确认 | 主档定义基础结构，门店策略保留覆盖语义 | 素材库、真实门店冲突和异步导入结果待接入 |
| 渠道商品 | 渠道库分组、商品列表、前台分类筛选、加入/编辑/详情、渠道差异字段、发布入口 | 仅分渠道协作且存在渠道商品库时显示 | 平台实际字段权限与发布接口待接入 |
| 渠道分类与属性 | 渠道前台分类、渠道属性、渠道自定义属性 | 仅分渠道协作显示；字段归属按渠道职责 | 三方渠道元数据和权限待接口 |
| 商品模板 | 列表、搜索/筛选、创建编辑、字段配置、商品范围、渠道范围、复制、启停、删除、详情 | 模板只定义渠道资料复用，不替代主档 | 发布结果由发布中心承接 |
| 售卖范围 | 列表、详情、复制、批量停用、导出、启停确认、保存前冲突阻断 | 对统一/分渠道商品使用相同规则对象，不改变字段归属 | 真实冲突检测接口待接入；冲突规则不得保存 |

| 属性互斥 | 搜索、状态、详情、创建编辑、规格/做法/加料选择、商品范围、启停删除 | 使用当前模式可见商品作为适用范围 | 真实冲突校验待接口 |
| 必选商品 | 搜索、状态、创建编辑、商品选择、门店类型、导入、异常查看、启停复制删除 | 规则商品沿用当前商品身份 | 导入结果、门店冲突待接口 |
| 商品推荐 | 筛选、详情、创建编辑、商品/渠道/门店/时间/优先级、复制启停删除 | 推荐配置不改变商品字段归属 | 渠道下发仍由发布中心处理 |
| 发布中心 | 发布批次、渠道/门店任务、进度、错误、展开详情、失败重试 | 所有模式的实际下发统一从此处治理 | 真实任务日志和重试接口待接入 |
| 映射治理 | 映射关系、搜索筛选、刷新、重新校验、差异查看、关系调整反馈 | 主要服务分渠道及平台商品治理 | 平台映射接口待接入 |
| 差异巡检 | 发起任务、进度/重试、差异字段对照、覆盖/接受/忽略及确认 | 企迈值和平台值的处置遵守字段职责 | 平台快照和主档审核接口待接入 |
| 门店商品 | 管理/覆盖视图、筛选、分类快捷导航、排序、上下架、沽清、编辑、日志导出、详情 | 从主档/渠道商品继承后维护门店允许覆盖项 | 服务端分页和批量部分失败待接口 |
| 门店分类 | 筛选、分类列表、门店范围、限时配置、保存删除确认 | 使用渠道前台分类语义，不回写主档后台分类 | 真实门店范围接口待接入 |
| 门店商品属性 | 规格、做法、加料三类门店执行页；加料筛选、库存、上下架、改价等操作 | 受全渠道上下架/库存开关控制 | 打印、日志等外部能力按接口接入 |
| 门店区域 | 列表、搜索、商品/门店统计、商品选择器、移除确认、保存 | 用于门店执行范围，不新增平台绑定职责 | 区域门店数据待接口 |
| 商品设置 | 紧凑设置分区、固定保存、渠道差异设置、商品推荐入口、全渠道策略入口 | 策略入口只在设置内出现 | 保存、权限、未保存离开需接生产接口 |
| 全渠道商品管理策略 | 原有协作方式、维护位置、能力、渠道库分组、连接要求、校验和影响预览 | 是所有菜单显隐、字段职责和任务归属的基线 | 不新增未确认字段；保存不等于发布 |
| 开放接口 | **待补齐**：应用管理、凭证与 Webhook、调用记录和文档尚无当前业务字段与能力开关 | 应按客户能力和权限显示，不默认暴露 | 需先取得旧系统字段、权限与安全规则，禁止按原型自行发明 |
