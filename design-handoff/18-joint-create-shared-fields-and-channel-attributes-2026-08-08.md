# 联合创建：共用资料一次填写，渠道属性同页维护

## 决策

渠道商品库“新建商品（主档 + 渠道商品）”仍是一条完整的一次创建流程，不拆成“先建主档、再维护渠道资料”两步。

表单按职责分区：

1. 主档基础资料；
2. 主档商品结构；
3. 渠道展示资料；
4. 渠道售卖资料；
5. 渠道补充资料；
6. 渠道专属属性。

## 继承与填写规则

| 内容 | 联合创建行为 |
| --- | --- |
| 渠道商品名称 | 默认使用主档名称，不重复展示输入 |
| 渠道商品主图 | 默认使用主档主图，不重复上传 |
| 规格、做法、加料结构 | 默认继承主档，不重复创建结构 |
| 前台分类 | 在渠道展示资料中带出映射默认值，可修改 |
| 列表简述、详情、标签、角标 | 在渠道展示资料中直接填写 |
| 渠道规格售价 | 直接继承主档规格售价，渠道区不重复展示或维护 |
| 起购限购、分时段、售卖方式 | 在渠道售卖资料中直接填写 |
| 渠道补充资料、平台专属字段 | 根据类目、商品库渠道和企迈参与方式动态展示并填写 |

用户点击一次保存后，系统同时创建商品主档和当前商品库的渠道商品。创建后“维护渠道资料”用于后续调整，不是完成首次创建的必经步骤。

## 原型落点

- 恢复“渠道展示资料、渠道售卖资料、渠道补充资料、渠道专属属性”页签与表单章节。
- 主档基础区不额外堆叠继承说明卡，由页签和字段分区直接表达职责。
- 渠道展示资料增加前台分类等渠道基础属性，不重复出现商品名称和主图。
- 渠道售卖资料不展示规格售价，保存时直接使用主档规格售价。
- 保存载荷同时记录主档值、渠道属性值和继承来源。
