- [ ] 表格、卡片、表单和弹窗的使用符合对象数量与任务类型。

## 组件

- [ ] 已先复用同目录或业务私有组件。
- [ ] 已查询统一组件的当前 Props、Events、Methods 和 Slots。
- [ ] 未用 `div/span` 静态模拟输入框、开关、Tab、分页、弹窗或树。
- [ ] 机构/门店、媒体、导入导出使用统一业务组件。
- [ ] 行内高频操作不超过 3 个，其余已收纳。

## 交互与状态

- [ ] loading、success、first-empty、filtered-empty、error、no-permission 已覆盖。
- [ ] submitting 和 partial-success 已覆盖或说明不适用。
- [ ] 状态有文字，不只靠颜色或图标。
- [ ] 批量操作展示选中数、范围、成功数、失败数和原因。
- [ ] 删除、禁用、覆盖、取消沽清等操作有二次确认。
- [ ] 保存中防重复，离开长表单时处理未保存变更。

## 工程

- [ ] Vue 页面遵循 Vue 2.7、Options API 和目标仓库代码风格。
- [ ] 路由、API、权限、国际化和 Store 位于正确子应用。
- [ ] 未编造组件 API 或接口字段。
- [ ] 保留真实数值 `0`，空值统一为 `--`。
- [ ] KeepAlive 返回、筛选恢复、监听器和定时器清理正确。
- [ ] lint、类型检查、构建或等价验证已执行。
