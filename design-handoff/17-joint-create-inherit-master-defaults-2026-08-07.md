# 联合创建默认继承主档资料

> 日期：2026-08-07  
> 状态：已被 2026-08-08 的“共用资料一次填写、渠道属性同页维护”决策修订  
> 替代：此前联合创建页并排展示“主档商品名称 / 当前渠道商品名称”及完整渠道资料的方案

> 修订说明：本文件“渠道差异后置维护”的范围过大。最终规则见 `18-joint-create-shared-fields-and-channel-attributes-2026-08-08.md`：只省略与主档重复的名称、主图和结构；渠道独有属性仍在创建时维护。

## 决策

渠道商品库“新建商品（主档 + 渠道商品）”采用“主档一次填写、渠道默认继承、差异后置维护”。创建页不再让用户重复填写主档已经能够提供的渠道字段。

创建页展示：

- 主档基础资料；
- 主档商品结构；
- 当前商品库适用、由企迈维护且无法从主档推导的平台专属字段。

创建渠道商品时自动生成：

| 渠道内容 | 默认来源 |
| --- | --- |
| 商品名称 | 主档商品名称，关系为跟随主档 |
| 商品图片 | 主档主图 |
| 前台分类 | 商品类目映射或品牌默认映射 |
| 规格、做法、加料 | 完整继承主档结构和启用范围 |
| 基础售价 | 主档规格基础价 |

若前台分类无法唯一映射，只补充分类选择，不展开完整渠道资料。需要与主档不同的名称、图片、分类、售价、描述或启用范围时，创建完成后从“维护渠道资料”单独修改。

## 边界

- 界面省略重复字段，不代表合并主档与渠道商品对象。
- 服务端仍分别写入两个对象、建立主档引用并记录继承状态。
- 联合创建不延伸为联合编辑；“编辑商品主档”和“维护渠道资料”继续分开鉴权、分开保存。
- 标准商品和套餐商品继续使用各自原有类目、字段、默认值、联动和校验。

## 原型落点

- 联合创建表单移除并排的“当前渠道商品名称”输入及完整渠道展示/售卖资料章节。
- 顶部创建进度只统计当前确实需要用户完成的字段。
- 页面以紧凑提示说明渠道商品将继承哪些信息，以及创建后从何处维护差异。
- 平台专属字段仍按当前商品库包含渠道及企迈参与方式动态出现。
