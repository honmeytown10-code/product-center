# 商品中心设计基线

## 目录

- 页面外壳
- 视觉 Token
- 信息密度
- 组件与交互
- 页面状态
- 适配与可访问性

## 页面外壳

- 默认运行在 Console 2.0 基座内，只设计业务内容区。
- 不重复顶部品牌/机构切换、全局搜索、帮助、通知、账号入口、左侧菜单、多页签和面包屑。
- 内容区外边距使用 `12px`，白色容器使用 `8px` 外层圆角。
- 页面按 `1440px` 及以上桌面环境设计；业务内容应能在约 `1180–1240px` 的可用宽度内保持稳定。
- 登录、打印、独立嵌入、全屏大屏或明确 `hideMenuHeader` 页面才脱离标准外壳。

## 视觉 Token

### 尺寸与间距

| 项目 | 规则 |
| --- | --- |
| 基础字号 | `14px` |
| 辅助文字 | `12px` |
| 页面/面板标题 | `16–20px`，避免营销式大标题 |
| 默认行高 | `24px` |
| 控件尺寸 | 统一组件的 `small` |
| 间距 | 只从 `4 / 8 / 12 / 16 / 24px` 选择 |
| 外层圆角 | `8px` |
| 弹窗/内层卡片 | 跟随现有组件，不擅自使用 16–24px 大圆角 |

优先使用：

```css
--console-spacing-xs: 4px;
--console-spacing-sm: 8px;
--console-spacing-md: 12px;
--console-spacing-lg: 16px;
--console-spacing-xl: 24px;
--console-main-padding: 12px;
```

### 色彩

主色由基座动态提供，默认品牌色仅作为兜底：

```css
color: var(--colorText, rgba(0, 0, 0, 0.88));
color: var(--colorTextSecondary, rgba(0, 0, 0, 0.65));
color: var(--colorPrimary, #00b460);
background: var(--colorBgContainer, #fff);
background: var(--colorBgLayout, #f5f5f5);
border-color: var(--colorBorderSecondary, #f0f0f0);
```

- 红色只表达失败、危险、异常或负向结果。
- 不把渠道颜色当成全页主题色。
- 状态不能只靠颜色表达，必须有文字。
- 存量原型中的硬编码色值只可作为视觉证据；生产实现改用主题变量或现有组件 Token。

## 信息密度

- 筛选区优先 3–4 列，默认一至两行；更多条件收入“展开筛选”。
- 状态 Tab、条件筛选、搜索/操作栏、主内容区分层组织，不把所有控件压在同一行。
- 表格操作栏通常左侧放搜索或当前范围，右侧按“辅助操作 → 更多操作 → 唯一主操作”排列；主操作位于最右并使用主题主色。
- 查询区的“重置/查询”靠右成组；导入、导出、同步、批量设置按业务优先级排列。
- 表格关键标识列、状态列和操作列保持稳定可见；允许横向滚动，不隐藏关键业务列。
- 商品名称旁可展示缩略图、商品 ID、类型或少量标签，但避免堆叠多层胶囊。
- 金额与数量右对齐或使用稳定宽度；空值显示 `--`，数值 `0` 保留。
- 行内操作不超过 3 个；其余收入“更多”。

## 组件与交互

优先级：

```text
同目录现有组件
  > 商品中心业务私有组件
  > vue-kylin
  > qm-form
  > qmai-ui / Element
  > 新建自定义组件
```

- 标准列表优先 `QmList + QmSearch + QmListTable`。
- 同仓库已使用复杂表格时，才继续用 `ProTable / ProTableV2`。
- 复杂、联动、动态表单优先 `qm-form`；少量简单字段可用 `el-form`。
- 门店/机构使用现有组织选择器，媒体使用统一素材库，导入导出使用统一任务组件。
- 搜索、翻页使用局部 loading；保存按钮 loading 并防重复提交。
- 触发批量任务后展示总数、成功数、失败数和可查看的失败原因。

## 页面状态

每个数据页面至少设计：

| 状态 | 要求 |
| --- | --- |
| loading | 保留页面骨架，局部加载 |
| success | 正常数据与操作 |
| first-empty | 解释用途并给主操作 |
| filtered-empty | 保留筛选条件并提供清空/调整 |
| error | 错误说明与重试 |
| no-permission | 明确缺少权限，不伪装为空数据 |
| partial-permission | 屏蔽敏感字段或动作，遵循同模块策略 |
| submitting | 防重复并保留当前输入 |
| partial-success | 展示成功/失败明细 |

## 适配与可访问性

- 长商品名、长分类路径、长策略名要截断并提供完整查看方式。
- 键盘焦点、禁用态、错误态和必填态必须清楚。
- 图标按钮提供可访问名称或 Tooltip。
- 不用 hover 作为唯一信息入口。
- 表格固定列数量要克制，避免中心滚动区过窄。
