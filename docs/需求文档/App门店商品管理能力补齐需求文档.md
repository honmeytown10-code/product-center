### 一、概述

**文档信息**

| 版本号 | 日期 | 作者 |

#### 1. 需求背景

- 目标用户现状：门店店长、店员、运营会在日常营业中高频维护商品，但 App 端商品管理能力不完整，很多信息无法直接在门店端维护，仍需依赖总部或绕到其他端处理。
- 核心痛点：门店无法在 App 端高效完成商品新建、编辑、标签/角标维护、渠道调整与售卖属性配置，导致操作链路长、易出错、效率低。
- 实施约束：当前商品列表仍由 Android、iOS 原生页面承载，受发布时间约束，无法在本期将整条商品列表链路完全迁移为 RN，因此本期仅重写商品编辑页，并通过 OP 后台配置控制是否跳转至新的 RN 编辑页，以支持按品牌灰度放量，避免一次性影响全部品牌。
- 当前问题汇总：

| 问题点 | 问题描述 | 当前影响 |
|--------|----------|----------|
| 新建能力不完整 | 新建商品时缺少详情、描述标签、角标、关联档口等属性维护能力 | 门店无法独立完成建品 |
| 编辑能力不完整 | 编辑商品缺少销售渠道修改、生效渠道选择、关联套餐校验等逻辑 | 渠道调整风险高，容易误覆盖 |
| 技术改造窗口有限 | 商品列表仍为原生实现，本期无法整体重写 | 需要采用局部 RN 重写和灰度开关方案 |
| 属性管理入口不足 | 标签、角标维护与创建流程割裂，管理能力不完整 | 维护效率低，操作中断 |
| 移动端交互不顺手 | 选择器、颜色、图片、时间等交互不够贴合移动端习惯 | 学习成本高，易误操作 |

#### 2. 需求目标

- 业务目标：
  - 支持门店在 App 端独立完成标准商品的新建与编辑核心流程
  - 支持门店直接管理描述标签与角标，减少对总部依赖
  - 降低销售渠道误操作风险，避免错误关闭在售商品或误覆盖其他渠道

- 成功标准：

| 指标 | 当前状态 | 目标状态 |
|------|----------|----------|
| 门店端可独立完成商品新建 | 仅能完成部分基础信息维护 | 可完成本次 PRD 范围内全部必填属性配置 |
| 门店端可独立完成商品编辑 | 渠道和部分属性编辑能力缺失 | 可完成本次 PRD 范围内属性编辑与渠道生效范围选择 |
| 标签/角标维护闭环 | 创建流程与管理流程割裂 | 支持管理页维护，创建/编辑页直接选择使用 |
| 渠道误操作风险 | 关闭渠道和全渠道编辑缺少充分提示 | 关闭渠道即时校验，全渠道编辑明确覆盖风险 |

#### 3. 需求范围

- 包含：
  - 新建商品补齐详情、描述标签、商品角标、关联档口等属性维护
  - 编辑商品补齐属性编辑、销售渠道修改、生效渠道选择、套餐关联校验
  - OP 后台新增编辑页切换配置，用于控制商品列表点击编辑后是否跳转至 RN 编辑页
  - 原生商品列表保留不动，仅替换商品编辑入口的目标页面
  - 门店侧描述标签管理
  - 门店侧角标管理
  - 图片样式上传限制与说明文案优化
  - 移动端颜色、时间、选择器等交互优化

- 不包含：
  - 商品分类支持选择二级分类
  - 规格变更逻辑
  - 原生商品列表整体 RN 化重写
  - 账号体系、登录体系、权限系统重构
  - 后端接口、数据库结构详细设计
  - 第三方服务接入方案

### 四、功能说明

#### 功能 1：新建商品属性补齐

**功能描述**

用户可在 `新建商品页` 完成标准商品创建，并维护商品详情、描述标签、商品角标、关联档口等属性，解决门店无法独立建品的问题。

**用户流程**

```text
[门店商品列表 / 商品管理工具页]
  ↓
[进入新建商品页]
  ↓
[填写基础信息]
  ↓
[维护详情 / 描述标签 / 商品角标 / 关联档口]
  ├─ 成功 -> [点击创建商品] -> [创建成功提示] -> [返回商品列表]
  ├─ 失败（必填项未填）-> [拦截提交] -> [字段报错提示]
  └─ 失败（网络异常）-> [保留已填内容] -> [提示稍后重试]
```

**状态机**

| 状态名称 | 进入条件 | 退出条件 | 用户可见表现 |
|----------|----------|----------|--------------|
| 初始编辑态 | 进入新建商品页 | 用户开始输入或离开页面 | 空表单或预填表单 |
| 编辑中 | 任一字段被编辑 | 创建成功或返回离开 | 表单内容可修改 |
| 选择弹层态 | 点击分类/标签/角标/档口字段 | 完成选择或关闭弹层 | 覆盖弹层展示 |
| 校验失败态 | 点击创建但有字段不合法 | 修正字段后再次提交 | 错误提示、字段高亮 |
| 提交成功态 | 创建请求成功 | 返回列表 | 成功反馈文案 |

**字段规范**

| 字段名 | 类型 | 是否必填 | 长度限制 | 校验规则 | 错误提示 |
|--------|------|----------|----------|----------|----------|
| 商品名称 | 文本 | 是 | 1-20 字 | 去首尾空格后不能为空 | 请输入商品名称 |
| 商品分类 | 选择 | 是 | 1 项 | 必须选择一级分类 | 请选择商品分类 |
| 基础售价 | 数字 | 是 | ≤ 8 位 | 大于 0，最多两位小数 | 请输入正确的售价 |
| 商品详情 | 多行文本 | 否 | ≤ 500 字 | 允许为空 | - |
| 描述标签 | 多选 | 否 | 最多 3 个 | 超过 3 个不可再选 | 最多选择 3 个标签 |
| 商品角标 | 单选 | 否 | 1 个 | 允许清空 | - |
| 角标生效时间 | 时间 | 否 | 1 组 | 开始时间不得晚于结束时间 | 请选择正确的有效期 |
| 关联档口 | 多选 | 否 | 多项 | 允许为空 | - |

**文案规范**

| 场景 | 文案内容 |
|------|----------|
| 空状态 | 暂无可选数据 |
| 加载中 | 加载中，请稍候 |
| 操作成功 | 商品创建成功 |
| 操作失败 | 创建失败，请稍后重试 |
| 权限不足 | 当前无权限执行该操作 |
| 网络异常 | 网络异常，请检查后重试 |

**异常情况处理**

| 异常场景 | 触发条件 | 处理方式 | 用户反馈 |
|----------|----------|----------|----------|
| 网络断开 | 创建请求失败 | 不清空已填表单 | 网络异常，请检查后重试 |
| 数据为空 | 标签/角标/档口无可选数据 | 展示空状态，不阻塞其他字段 | 暂无可选数据 |
| 操作超时 | 提交超过 8 秒无结果 | 结束提交态，允许重新提交 | 操作超时，请稍后重试 |
| 权限不足 | 当前账号无创建权限 | 阻止创建 | 当前无权限执行该操作 |

#### 功能 2：编辑商品属性补齐与销售渠道修改

**功能描述**

用户可在 `编辑商品页` 修改本次迭代范围内的商品属性，并在销售渠道变更时完成即时校验、生效渠道选择和覆盖提示，解决编辑场景下的风险控制问题。本功能以 RN 页面承载，但接入方式采用“原生商品列表 + RN 编辑页”的局部替换模式，通过 OP 后台开关控制是否启用新的编辑页。

**接入与发布策略**

| 项目 | 说明 |
|------|------|
| 当前列表实现 | 商品列表继续使用 Android、iOS 原生页面 |
| 本期 RN 改造范围 | 仅商品编辑页 |
| OP 配置项 | 后台新增编辑页跳转开关，按品牌维度控制 |
| 开启状态 | 原生商品列表点击编辑时跳转 RN 编辑页 |
| 关闭状态 | 原生商品列表点击编辑时仍进入原生编辑页 |
| 目标 | 在不影响全部品牌的前提下快速上线紧急需求 |

**用户流程**

```text
[OP 后台开启或关闭编辑页跳转开关]
  ↓
[门店商品列表]
  ↓
[点击编辑]
  ├─ 开关开启 -> [进入 RN 编辑商品页]
  └─ 开关关闭 -> [进入原生编辑页]
  ↓
[进入编辑商品页]
  ↓
[修改商品基础信息/属性/销售渠道]
  ├─ 关闭某个渠道
  │   ├─ 未被套餐关联 -> [关闭成功，继续编辑]
  │   └─ 已被套餐关联 -> [立即弹窗拦截] -> [保持原开关状态]
  ↓
[点击保存修改]
  ├─ 单渠道视角 -> [直接保存] -> [保存成功]
  ├─ 全渠道视角 -> [弹出生效渠道选择弹窗]
  │   ├─ 选择目标渠道并确认 -> [保存成功]
  │   └─ 未选择渠道 -> [不可确认保存]
  └─ 失败（网络异常）-> [保留编辑态] -> [提示稍后重试]
```

**状态机**

| 状态名称 | 进入条件 | 退出条件 | 用户可见表现 |
|----------|----------|----------|--------------|
