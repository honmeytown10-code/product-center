# 商品模板模块 UI / 交互基线

更新时间：2026-08-01。本文件记录商品模板列表、创建编辑、模板商品与适用门店管理的当前设计与原型实现。业务字段与商品来源规则以当前代码为准。

## 1. 页面契约

| 项目 | 约束 |
| --- | --- |
| 任务域 | 渠道经营 / 商品模板 |
| 主要角色 | 渠道负责人、区域运营、品牌商品运营 |
| 核心任务 | 创建模板、维护商品与门店范围、准备发布任务 |
| 核心对象 | 商品模板、渠道、商品来源、商品/SPU、门店 |
| 来源规则 | 模板不是商品来源；来源由所选渠道和全渠道管理策略自动判定 |
| 保存结果 | 保存模板配置，不直接改变门店实际商品；实际变化通过发布中心形成发布批次 |
| 模式差异 | 统一维护与分渠道协作共用模板页面，自动判定的商品来源不同 |

页面使用“范围上下文 + 商品集合 + 门店范围”的模板骨架，不复制商品管理列表，也不把模板配置伪装成已经发布成功。

## 2. 模板列表

### 首屏结构

1. 状态视图：全部、已启用、已停用，显示真实数量。
2. 紧凑筛选：模板名称/描述/ID关键词、适用渠道。
3. 左侧模板分组：全部模板、业务分组、未分组及数量。
4. 右侧高密度表格：模板、商品来源、适用渠道、商品/门店范围、状态、操作。
5. 底部批量栏或总数信息。

不展示大标题和页面说明区；商品来源是比说明文案更重要的业务信息，直接作为稳定表格列呈现。

### 字段

| 字段 | 显示/来源 | 交互规则 |
| --- | --- | --- |
| 模板名称 | `record.name` | 点击进入模板范围管理；长名称截断并保留完整 title |
| 模板描述 | `record.description` | 与模板 ID 作为第二行辅助信息 |
| 商品来源 | `resolveTemplateProductSource` | 只读自动计算；多来源时显示“来源冲突/需拆分模板” |
| 适用渠道 | `record.channels` | 展示渠道短名称，不把渠道分组误当单一渠道 |
| 商品/门店范围 | `productCount/storeCount` | 保留真实数值 `0` |
| 状态 | enabled/disabled | 始终有“已启用/已停用”文字 |

### 动作

- 主操作：创建模板。
- 次操作：导入、导出。
- 行操作：管理、编辑；复制、启停、删除收进“更多”。
- 批量操作：批量启用、批量停用、批量删除；底部持续显示选中数量。
- 复制模板：复制商品和门店范围，副本默认停用，避免立即参与发布。
- 停用模板：仅阻止新的发布任务，不自动回滚已发布门店商品。
- 删除模板：删除模板范围配置，已存在发布记录不受影响。

### 分组

- 支持新增分组、重命名和删除。
- “全部模板”和“未分组”是系统分组，不提供删除。
- 删除业务分组时模板移至“未分组”，不连带删除模板。

## 3. 创建与编辑

### 字段与校验

| 字段 | 必填 | 校验与联动 |
| --- | --- | --- |
| 模板名称 | 是 | 最长 30 字；空值阻止保存 |
| 模板描述 | 否 | 最长 200 字，显示字数 |
| 所属分组 | 否 | 默认未分组，只改变列表组织 |
| 适用渠道 | 是 | 至少一个；渠道切换实时触发商品来源计算 |
| 商品来源 | 自动 | 只读；缺少分组或对应多个来源时阻止保存并展示原因 |

编辑已有模板并修改渠道时，页面明确提醒可能改变商品来源与发布目标。来源不唯一时要求拆分模板，不提供手工来源选择来绕过规则。

## 4. 模板商品与门店

### 顶部上下文

- 模板名称、描述、模板 ID、启用状态。
- 商品来源标签与来源说明。
- 适用渠道。
- 唯一主操作“创建发布任务”：模板停用、无商品或无门店时禁用。

“创建发布任务”进入发布中心，不在模板页面伪装为同步完成。

### 模板商品

| 字段 | 说明 |
| --- | --- |
| 排序 | 当前模板内顺序 |
| 商品识别 | 图片、名称、商品 ID、SKUID |
| 商品类型 | 标准商品/套餐商品，沿用原类型 |
| 前台分类 | 沿用当前商品分类字段 |
| 基础价格 | 显示两位小数，`0` 不显示为空 |
| 状态 | 可售、停售、草稿 |

- 商品选择器复用字段级商品选择组件，支持名称、商品 ID、SKUID、标识、分类、类型和分页筛选。
- 保存选择范围时反馈新增数量。
- “更新商品资料”说明来源、商品数及失效对象处理，再确认执行。
- 移除商品只修改模板；已经发布的数据不自动回滚，下一次发布后生效。

### 适用门店

| 字段 | 说明 |
| --- | --- |
| 门店名称 | 门店识别字段 |
| 所属机构 | 组织归属 |
| 区域 | 区域范围 |
| 状态 | 当前原型展示营业中 |

- 门店选择器支持门店、机构和区域搜索，显示已选数量并可清空。
- 同渠道下已被其他启用模板覆盖的门店禁选，并显示冲突模板名称。
- 当前模板已经选中的门店可继续保留，避免编辑时被自身冲突阻断。
- 移除门店只修改后续发布范围，不自动回滚门店已发布数据。

## 5. 弹窗与反馈

| 容器 | 触发 | 关键内容 |
| --- | --- | --- |
| 创建/编辑弹窗 | 创建、编辑 | 字段、渠道、自动来源、冲突、保存 |
| 分组弹窗 | 新增、重命名 | 分组名称、长度校验 |
| 商品选择器 | 添加商品 | 搜索、表格、已选数、分页、保存范围 |
| 门店选择器 | 添加门店 | 搜索、已选、冲突禁选、保存范围 |
| 更新确认 | 更新商品资料 | 来源、商品数、覆盖与失效对象说明 |
| 移除确认 | 移除商品/门店 | 对象、发布时间语义、不会自动回滚 |
| 启停/删除确认 | 行或批量操作 | 数量、发布影响、不可逆部分 |
| 导入弹窗 | 导入 | 文件选择、先校验、不即时创建 |

所有成功反馈使用页面内消息条，不调用浏览器原生确认框。
