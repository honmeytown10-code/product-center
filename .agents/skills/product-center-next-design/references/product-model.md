# 商品中心 Next 对象模型

## 核心对象

| 对象 | 回答的问题 | 主要内容 |
| --- | --- | --- |
| 商品主档 | 这是什么商品 | 商品身份、SPU/SKU、规格、做法、加料、套餐、标识和基础关系 |
| 渠道商品库 | 哪些渠道共用一套品牌级售卖资料 | 渠道分组、商品范围、共用渠道资料和平台扩展 |
| 渠道商品 | 该渠道团队准备把商品卖成什么样 | 渠道名称、前台分类归属、图片、价格、描述、售卖规则和平台属性；前台分类默认继承主档，可覆盖当前商品库归属 |
| 商品模板 | 哪些区域、门店和渠道存在经营差异 | 单一来源的商品集合、适用范围和经营覆盖值 |
| 发布批次 | 这次把哪个固定版本发布到哪里 | 来源、快照、目标、子任务、进度、结果和重试 |
| 门店渠道商品 | 具体门店、具体渠道实际可售什么 | 上下架、库存、沽清、门店覆盖值、发布和映射状态 |
| 平台真实商品 | 三方平台实际存在什么 | 平台商品与 SKU 标识、审核和平台状态 |
| 商品映射 | 企迈 SKU 与平台 SKU 如何对应 | 关联依据、健康状态、冲突、失效和变更记录 |

渠道商品必须引用商品主档，不产生独立商品或 SKU 身份。模板不是商品来源，来源由渠道策略、协作方式和渠道商品库分组自动判定。

## 三种渠道处理方式

| 渠道方式 | 商品资料入口 | 发布行为 | 映射要求 |
| --- | --- | --- | --- |
| 自营渠道 | 商品主档维护身份结构，渠道商品库维护销售资料；统一管理时只有一个默认商品库 | 生成企迈侧门店渠道商品 | 不进入三方映射 |
| 三方渠道由企迈管理 | 渠道商品库维护共用资料与平台扩展 | 同时生成企迈侧任务和平台发布任务 | 发布后自动建立或校验，异常进入治理 |
| 三方渠道由平台维护 | 平台维护平台专属资料；启用企迈经营能力时，由所属渠道商品库准备企迈侧门店渠道商品 | 不发布平台商品资料；按商品库下发企迈侧商品 | 接单或上下架/库存能力启用时必须建立 |

“平台维护资料”只表示平台专属字段不由企迈维护，不等于渠道退出企迈商品链路。只要企迈负责接单、上下架或库存中的任一能力，该渠道就必须归属渠道商品库、下发企迈侧门店渠道商品并建立映射；仅在未启用任何企迈经营能力时，才不要求商品库归属和门店绑定。

暂不接入的渠道不进入商品、发布、授权和映射链路。

## 继承与覆盖

```text
商品主档
  → 渠道商品：继承身份与结构，覆盖渠道销售资料
    → 商品模板：覆盖区域、门店、渠道经营差异
      → 门店渠道商品：承接具体门店经营状态
```

- 规格与 SKU：主档维护结构、身份和规格售价；渠道只能启用/禁用并维护库存等渠道销售值，规格售价直接继承主档。
- 做法与加料：主档维护允许集合和关系；渠道只能缩小可售子集。
- 主档新增结构：渠道显示“待确认”，默认不自动启用。
- 主档停用结构：下游强制禁用并生成待发布差异。
- 下游不得启用上游不存在或已禁用的对象。
- 统一管理只把多个渠道商品库合并为一个默认商品库，不隐藏菜单，也不合并主档与渠道商品的底层数据职责。
- 从渠道商品库发起的“同时创建主档与渠道商品”是编排操作：一次提交写入两个对象，但渠道商品仍必须引用新建主档。
- “同时创建”不取代“选择已有主档”。两种协作模式均保留选择入口；已存在当前商品库渠道商品的主档禁止重复添加，仅主档商品可补建渠道商品。
- 联合创建的录入界面中，共用资料只填写一次：前台分类在主档资料区维护并作为渠道初始默认值；渠道名称、图片、规格/做法/加料结构和规格售价默认从主档生成，不并排展示重复输入。创建后渠道商品可从主档已定义的启用分类中覆盖当前商品库前台分类归属，但不提供规格售价的主档覆盖入口。
- 联合创建不延伸为联合编辑。后续必须分别进入主档编辑页和渠道商品编辑页、分别鉴权与保存；主档名称与渠道名称分别保存，渠道名称默认跟随主档，可显式独立。
- 规格/SKU、做法和加料的结构只允许在主档层增删改；渠道层只能维护启用子集及库存等渠道销售值，规格售价继承主档。

## 权限对象

渠道商品库既是资料归属对象，也是由固定渠道权限动态推导的数据范围对象。权限至少拆为：

1. 商品中心页面权限：决定是否可进入商品主档、渠道商品、发布等页面。
2. 固定渠道数据范围：决定账号可查看、选择或管理的 channelId；系统结合当前渠道—商品库分组关系实时推导可见商品库 ID 集合。
3. 对象操作权限：查看、选择已有主档、创建主档、创建渠道商品、编辑、移出、导入、导出、发布和授权管理分别控制。

商品库权限不得只用菜单权限代替。商品库改名不改变固定渠道授权；合并、拆分、删除和协作方式切换必须按最新分组重新推导范围并审计，且不得把部分渠道权限自动提升为统一默认商品库的全量权限。修改商品库公共资料需要覆盖库内全部渠道，或具备显式共享资料操作权限。

## 权威边界

| 数据或能力 | 权威系统 |
| --- | --- |
| 商品主档、渠道商品、模板、发布快照、门店渠道商品 | 商品中心 |
| 品牌协作方式、三方商品维护位置、企迈参与能力、渠道商品库分组 | 商品中心 |
| 平台字段和能力规则、平台接口执行、平台商品 ID | 平台服务 |
| 映射关系、授权令牌、平台店铺绑定 | 平台服务 |
| 合同渠道范围、授权模式、计费资格和迁移锁定 | OP/合同配置 |

商品中心展示平台规则、授权摘要和映射处理入口，但不直接维护其权威数据，也不直接调用三方平台。
