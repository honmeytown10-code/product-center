# 02. 商品资料

## 1. 页面范围

商品资料包含三个正式菜单页：

1. 商品管理（统一维护）或商品主档（分渠道协作）。
2. 分类与属性。
3. 配方与营养。

统一维护只合并用户操作，不合并底层对象；分渠道协作明确拆开主档与渠道销售资料。

| SKU ID | 只读 | 保存后生成 |
| SKU 编码 | 按配置 | 唯一性校验 |
| 商品条码 | 否 | 支持扫码/输入，多条码时打开管理弹窗 |
| 商品标识 | 否/接入必填 | 映射和外部系统识别 |
| 销售价 | 统一维护必填 | 分渠道主档仅参考价或不维护 |
| 市场价 | 否 | 必须大于等于销售价时按业务校验 |

规格区按钮：选择规格、快捷新建规格、添加规格值、批量填充、生成组合、排序、恢复上次、删除 SKU。删除存在引用的 SKU 时阻止并打开影响抽屉。

### 做法

字段：做法分组、做法值、标识码、备注、温馨提示、是否多选、最少/最多选择数、默认值、是否启用、做法加价（统一维护销售资料）。

按钮：从做法库选择、快捷新建、排序、设置默认、移除。移除只解除当前商品关系，不删除做法库对象。

### 加料

字段：加料分组、加料商品、加料规格、初始/销售价格、单品限购、总量起购/限购、是否必选、默认项、未选择提示、是否启用。

按钮：选择加料分组、批量关联、调整规则、排序、移除。统一维护可维护销售值；分渠道主档只维护允许关系。

### 套餐分组

字段：分组名称、编码、备注、必选/可选、选择方式（按数量/按种类）、最少/最多选择数、重复选择、子商品、子商品规格、加价、默认项、售罄替换规则、排序。

按钮：新增分组、添加商品、批量设置加价、复制分组、排序、删除分组。被门店或模板引用的共享分组修改时提供“同步修改/另存为新分组”。

## 2.8 渠道属性（统一维护）

先展示适用渠道摘要。自营渠道只显示共用销售字段；由企迈管理的三方渠道按平台服务能力矩阵动态生成局部表单；平台自行维护渠道不显示平台字段。

每个渠道分组至少支持：

- 平台类目（必填规则动态返回）；
- 渠道商品名称/描述是否覆盖公共值；
- 渠道主图/详情图及尺寸校验；
- 包装、配送、售卖时段等平台扩展；
- 平台审核资料与提示；
- 字段校验状态：未配置、待完善、可发布、平台规则已变化。

按钮：展开/收起、从公共资料复制、恢复公共值、校验当前渠道、查看平台规则。不得提供“将所有平台字段互相覆盖”的模糊操作。

## 2.9 其他字段

生产地、原料说明、配方关联、营养信息摘要、打印统计、税务扩展、自定义字段。自定义字段按商品类型和类目动态出现，并显示来源、是否必填和配置入口。

# 3. 商品详情

## 3.1 顶部摘要

商品图片、名称、商品 ID、SKUID、类型、主档状态、资料状态、数据来源、最近更新。统一维护增加渠道发布摘要；分渠道协作增加渠道商品库使用进度。

页面按钮：编辑、创建发布（统一维护）、查看渠道进度（分渠道）、复制商品、更多（归档、日志）。

## 3.2 详情 Tab

| Tab | 字段 |
| --- | --- |
| 基础资料 | 名称、类型、类目、后台分类、编码、单位、标识、标签、备注 |
| 商品结构 | SKU、规格、做法、加料、套餐子项、状态 |
| 展示与销售 | 统一维护显示图片、描述、价格、售卖规则、会员、税务 |
| 渠道进度 | 渠道商品库、覆盖渠道、确认状态、最近发布、异常数量 |
| 配方与营养 | 配方状态、配料、营养口径、覆盖策略 |
| 发布与门店 | 发布批次、门店覆盖、平台状态、映射状态 |
| 操作记录 | 谁在何时改了什么，支持前后值 |

详情字段为空显示 `--`；敏感字段无权限时整项隐藏。

## 3.3 渠道进度抽屉

字段：商品库、覆盖渠道、是否已加入、资料状态、待确认结构数、发布状态、门店覆盖、负责人、更新时间。按钮：打开渠道商品；只有对应权限时显示。

# 4. 分类与属性

## 4.1 页面契约

| 项目 | 规格 |
| --- | --- |
| 建议路由 | `/goodsCenter/foundations` |
| 页内视图 | 后台分类、前台分类、规格、做法、加料、标签、角标、商品系列、随心配 |
| 主骨架 | 左侧视图导航；右侧按对象使用树表或高密度表格 |
| 权限 | 每个视图独立查看、新建、编辑、删除、排序、发布权限 |

统一维护与分渠道协作均在商品主档显示后台分类和前台分类；标签、角标和系列等渠道资料根据归属进入渠道商品上下文，页面顶部必须显示当前商品库。

## 4.2 后台分类

### 筛选/字段

搜索：分类名称、编码；筛选：层级、状态、来源。  
表格/树字段：排序、分类名称、分类编码、父级路径、层级、关联商品数、状态、来源、更新时间、操作。

### 按钮

新增一级分类、在当前分类下新增、编辑、排序管理、启用/停用、查看关联商品、删除、导入/导出。

### 编辑弹窗（720px）

字段：上级分类（创建子级时只读/可选）、分类名称（必填）、分类编码、描述、备注、状态。按钮：取消、保存。

### 删除弹窗

显示子分类数、关联商品数、模板/规则引用数。有引用时阻止删除并提供“查看关联”；无引用时红色“删除”。

## 4.3 前台分类

### 字段

排序、分类图标、分类名称、分类标识、分类标签、父级路径、关联商品数、展示状态、适用渠道、更新时间、操作。

### 编辑字段

上级分类、名称、标识、标签、描述、备注、图标、Banner、适用渠道、前台隐藏、经典菜单隐藏、是否必选分类、仅选该分类不可下单等已开通业务规则。

每个展示规则旁说明具体前台和影响，不使用双重否定文案。

### 按钮/弹窗

新增分类、新增二级分类、编辑、排序管理、同步分类排序、查看关联商品、删除。同步排序弹窗显示模板数、门店数、渠道、生效时间和覆盖后果。

## 4.4 规格库

表格字段：规格名称、规格值、规格值编码、关联商品数量、状态、更新时间、操作。  
筛选：名称/编码、状态、是否被引用。  
按钮：新增规格、批量导入、列设置、编辑、编辑规格值、查看关联商品、停用、删除。

规格编辑弹窗字段：名称（必填）、描述、规格值行（名称必填、编码、状态、排序）。规格值可添加/移除。删除存在关联时阻止；停用提示下游强制禁用和待发布差异。

## 4.5 做法库

表格字段：做法名称、做法值、标识码、备注、温馨提示、关联商品数、多选、选项数量范围、状态、操作。

编辑字段：做法名称、做法值列表、值编码、备注、提示、是否多选、最少/最多选择数、默认值、状态。按钮：新增做法、排序、编辑、查看关联、停用、删除。

## 4.6 加料库

采用“加料类型 + 加料商品”层级表格。字段：类型、排序、加料商品名称、SKU、初始价格、关联商品数、状态、创建时间、操作。

加料类型编辑：名称、编码、说明、排序、状态。  
加料商品编辑：引用商品/SKU、默认价格、默认限购、独立售卖、状态。  
按钮：创建加料、发布加料类型、批量关联商品、排序、编辑、查看关联、停用、删除。

## 4.7 标签

子 Tab：描述标签、点单标签、统计标签。  
表格字段：标签分组、标签、背景色、字体色、效果预览、适用渠道/场景、关联商品数、来源、创建时间、操作。

弹窗：新增分组（名称、说明、排序）；新增标签（所属分组、名称、样式、背景色、字体色、适用范围、状态）。颜色输入同时提供预设和合法 Hex 校验。

## 4.8 角标

字段：角标名称、类型、背景/图片、预览、默认有效期、适用渠道、关联商品数、来源、状态、操作。

编辑弹窗：名称、类型（文字/图片）、背景色或素材、字体色、默认有效期、适用渠道、状态。删除引用中角标时提供替换或解除流程。

## 4.9 商品系列

字段：系列名称、系列图片、关联商品数、展示顺序、适用渠道、启用状态、更新时间、操作。

编辑使用 840px 弹窗或独立页：名称、图片、说明、商品选择、排序、适用渠道、启用状态。按钮：新增系列、编辑商品、排序、启停、删除。

## 4.10 随心配

表格字段：分组 ID、名称、编码、备注、商品标识、条码、配置方式、按种类选择、是否必选、购买数量限制、关联商品数、状态、操作。

编辑字段：名称、编码、备注、可选项列表、商品/SKU、加价、配置方式、必选、最少/最多、按种类规则、默认项、状态。复杂商品选择使用 1120px 双列表弹窗。

## 4.11 通用弹窗

分类/属性页面统一提供：关联商品抽屉、排序弹窗、删除阻止弹窗、停用影响弹窗、导入校验弹窗、操作结果弹窗。所有引用数量可点击进入带筛选的商品列表。

# 5. 配方与营养

## 5.1 页面契约

| 项目 | 规格 |
| --- | --- |
| 建议路由 | `/goodsCenter/recipes` |
| 页内视图 | 配料库、默认配方、门店配方策略、营养成分 |
| 主要角色 | 商品研发、供应链、商品负责人 |
| 主骨架 | 左侧对象/规格定位 + 右侧层级配置；列表视图使用高密度表格 |

## 5.2 配料库

子 Tab：配料、原料素材。

### 配料列表字段

分组名称、配料名称、配料编码、三方编码、单位、营养状态、引用配方数、状态、更新时间、操作。

筛选：名称/编码、分组、单位、营养是否配置、引用状态、启停状态。

按钮：新增配料分组、批量导入、导出、编辑、查看引用、停用、删除。

### 配料分组编辑弹窗（840px）

字段：分组名称、分组编码、说明、配料明细表（排序、名称、编码、单位、三方编码、状态）。按钮：添加配料、取消、保存。

### 原料素材

字段：原料名称、展示图、别名、说明、关联配料数、更新时间、操作。编辑弹窗使用统一素材库；删除前显示引用。

## 5.3 默认配方

### 列表字段

商品、商品分类、SKU/组合数量、配置状态、配方完整度、营养计算状态、最近更新、操作。

筛选：商品名称/ID、分类、配置状态、是否存在多规格差异、更新时间。

按钮：添加商品、配料库、甜度公式、基础设置、导入、导出、查看详情、删除配方。

### 配方详情/编辑

顶部字段：商品、SKU、规格组合、当前配方版本、来源、更新时间。  
配方明细列：配料、用量、单位、损耗率、成本、营养贡献、做法影响、加料分组、备注。  
按钮：获取最新商品配置、重新生成组合、减少组合维度、新增加料分组配方、复制、粘贴、清空、删除行、保存配方。

多规格不能只显示 SPU 汇总；SKU/做法/加料组合使用左侧树或固定维度栏切换。

### 基础设置弹窗（720px）

字段：打印分隔符、启用配方编码、启用配方图片、加料参与配方、启用新版本配方、启用甜度、甜度计算规则。按钮：取消、保存设置。

### 组合维度弹窗（840px）

字段：规格、做法、加料维度，当前组合数、预计新组合数、被忽略维度。按钮：取消、确认并重新生成。确认前提示会覆盖未保存组合。

## 5.4 门店配方策略

### 列表字段

策略名称、适用门店、覆盖商品数、优先级、启用状态、更新时间、操作。

按钮：新建策略、基础信息、配方商品、启停、删除。

### 策略基础信息

字段：策略名称（必填）、状态、优先级、适用区域/门店、备注。按钮：删除、取消、保存配置。与其他策略冲突时提交前显示冲突门店和优先级。

### 配方商品

字段：商品、SKU、默认配方版本、门店覆盖状态、差异摘要、更新时间、操作。按钮：添加商品、去配置、移除、批量恢复默认。

删除/停用策略确认说明相关门店将恢复哪个默认配方以及生效时间。

## 5.5 营养成分

### 列表/树

字段：商品规格、SKU ID、商品标识、营养配置状态、计算来源、每份重量、能量、蛋白质、脂肪、碳水、更新时间、操作。

筛选：商品名称/ID、分类、配置状态、计算来源、是否缺少配料营养。

### 编辑字段

| 字段 | 说明 |
| --- | --- |
| 计算口径 | 每份/每 100g/每 100ml |
| 每份重量 | 与商品分量/配方单位关联 |
| 数据来源 | 配方自动计算/手工覆盖/外部导入 |
| 能量 | kJ/kcal 单位明确 |
| 蛋白质、脂肪、碳水 | 数值 `0` 与未配置区分 |
| 糖、钠、膳食纤维等 | 按品牌字段配置显示 |
| 覆盖原因 | 手工覆盖自动值时必填 |
| 展示渠道 | 选择哪些前台展示 |

按钮：重新计算、编辑营养、批量导入、导出、恢复配方计算、查看计算明细。

### 计算明细抽屉

字段：配料、用量、营养基值、损耗/换算、营养贡献、缺失原因。底部按钮：关闭、打开配料维护。

## 5.6 配方与营养状态

至少覆盖：无商品、商品无规格、配料库为空、配料营养缺失、组合数过大、配方被门店策略覆盖、重新生成部分失败、无成本价权限、自动计算数据过期。
