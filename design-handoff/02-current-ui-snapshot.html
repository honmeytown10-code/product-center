展板 3 · 校验错误态：存在未分组渠道，保存被拒绝

唯一的错误反馈是页面顶部一条橙色提示条，不定位到具体出错的控件。摘要条里同时有一处橙色文案「另有 2 个渠道未分组」。两处提示相距很远，用户需要自己关联。此处仅展示 Header + 提示条 + Section 1。
