# 列表密度与配方营养模块交互基线

更新时间：2026-08-01。本文件记录本轮已经落地的跨页面密度规则，以及“配方与营养”模块当前可操作范围。

## 1. 列表首屏密度

- 商品主档、渠道商品、分类与属性等高频对象页不再使用大标题、解释文案和策略事实条叠加占据首屏。
- 首屏顺序统一为：状态/业务 Tab → 筛选 → 对象快捷导航 + 数据表。页面职责由菜单名和字段结构表达。
- 仅在范围直接决定编辑归属或提交目标时显示单行范围条；字段归属等低频说明进入覆盖式弹窗，不挤压数据区。
- 顶部操作遵循“一页一个主操作”；低频配置收进“更多配置”，危险操作使用明确影响范围的二次确认。

## 2. 分类快捷导航

| 页面/模式 | 左侧快捷导航 | 结构化筛选 |
| --- | --- | --- |
| 商品主档（分渠道协作） | 后台分类 | 后台分类、商品类型及原有业务条件 |
| 渠道商品（分渠道协作） | 前台分类 | 前台分类、商品类型及渠道业务条件 |
| 商品管理（统一维护） | 后台分类 / 前台分类可切换 | 同时保留前后台分类及原有业务条件 |

商品类型只有标准商品、套餐商品两项，不作为占据整列的对象导航；它仍是创建入口与列表筛选的重要业务条件。分类计数随状态、搜索和已应用筛选联动。

## 3. 配料库

- 配料分组、配料项、原料均支持新增、编辑、删除与操作结果反馈。
- 删除分组前校验引用；存在配料项时阻止删除。
- 配料支持 CSV 导出；导入使用文件选择和校验弹窗，不使用无反馈的假按钮。
- 工具栏只突出新增配料；新增分组、导入/导出保持次级操作。

## 4. 营养成分

- 使用“商品 → 规格 → 做法/营养值”三栏对象定位，不增加页面说明卡。
- 商品名称/ID和配置状态筛选可用；商品添加只展示尚未进入营养管理的商品。
- 切换规格会同步定位其首个做法；做法可选中并展示当前营养值。
- 编辑弹窗保留热量、蛋白质、脂肪、碳水、钠及现有单位；输入限制为最多两位小数，空值允许清空配置。
- 保存或清空后更新规格/做法状态并提供页面内反馈；原料库按钮跳转到配料库。

## 5. 商品配方与门店策略

- 配方商品列表支持商品名称、商品 ID 搜索；状态显示“已配置组合数/全部组合数”，不使用模糊的单一文案。
- “添加商品”为唯一主操作；加料分组、配料库、基础设置、甜度计算公式收敛到“更多配置”。
- 添加商品使用多选弹窗并排除已加入商品；移除商品显示已经配置的组合影响。
- 门店配方策略继续使用少量复杂策略卡片；开关有文字状态和可访问名称。
- 删除策略必须展示恢复为总部默认配方的门店影响，不调用浏览器原生确认框。

## 7. 本轮补充确认

- “全渠道配置”不再作为独立左侧菜单；商品设置内已有“全渠道商品管理策略”入口，低频配置从该入口进入。
- 策略商品沿用原有独立快照语义：加入策略时复制总部默认配方形成快照，之后不跟随总部默认配方变化；移出策略后适用门店恢复使用总部当前默认配方。
- 配方详情已补齐组合维度选择、配方编码、优先级、初始/测算甜度、配料用量、复制粘贴、清空、删除、保存、导入校验、导出和重新生成影响确认。

- 策略商品已补齐搜索、添加、生成快照、导入校验、配置进度、进入配方配置和移除影响确认。
